# 快速开始

这一章带你从零到装好第一个技能,大概需要五分钟。

## 你需要先知道的事

- SkillDock 是一个独立的桌面应用,装上就能用,不依赖任何 CLI
- 它管理的对象是「技能」(含 `SKILL.md` 的目录),管理的方式是**符号链接**——中央技能库里只存一份文件,各 Agent 目录里的技能都是指向它的链接
- 技能从哪来:本地文件夹、GitHub 仓库、`.zip`/`.skill` 压缩包,或三个内置技能市场

## 推荐路径

- **全新用户**:按顺序读 [下载安装](./installation) → [第一个技能](./first-skill)
- **本机已经有一堆技能的用户**:装好应用后直接去「本机 skill 管理」页,把散落的技能收编进技能库,再回来看 [第一个技能](./first-skill)

## 本章涵盖内容

- [下载安装](./installation):macOS / Windows 安装包,以及被系统拦截时的放行方法
- [第一个技能](./first-skill):添加来源 → 确认 Agents → 安装 → 验证

完成标志:你能在「技能库」里看到技能,并且目标 Agent 的技能目录里出现了指向中央库的符号链接。
