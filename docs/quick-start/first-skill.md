# 第一个技能

从添加来源到 Agent 看到技能,一共三步。

## 第一步:添加一个来源

点左栏的 **+ 添加skills** 按钮,选择来源类型:

- **本地文件夹**:选一个含技能的目录(目录里每个含 `SKILL.md` 的子目录都会被视为一个技能)
- **GitHub 仓库**:填仓库地址,应用会克隆到应用数据目录的 `repos/` 并递归索引
- **压缩包**:`.zip` / `.skill` 文件,安全解压后入库

扫描完成后,添加弹窗会让你选择安装到哪些 Agents。如果开了「默认安装到已启用的 Agents」(设置 → 通用),这一步会自动勾选,点确定即完成。

## 第二步:确认 Agents 已启用

进左栏「agents」页:

- 应用启动时会自动探测本机装了哪些 Agent(内置 38+ 目标),探测到的会自动启用
- 没探测到但确实有技能目录的工具,可以点「重新检测」或手动添加自定义目录
- 每个已启用的 Agent 都有自己的管理入口,能看到它目录里的所有技能(包括不是通过 SkillDock 装的)

## 第三步:安装并验证

在「技能库」里点开任意技能:

- 打开某个 Agent 的开关,即完成安装——本质是建了一个符号链接,Agent 立即可见
- 卡片视图下也可以直接点行尾的 Agent 图标角标,不进详情页就能装/卸

验证:在该 Agent 的技能目录里 `ls -l`,会看到指向中央技能库（或其他来源目录）的软链。

## 常见问题

### 安装失败提示「真实目录冲突」

目标位置已经是一个真实目录(不是软链)。SkillDock 永远不会覆盖真实目录——先把旧目录改名或移走,再重新安装。

### 技能改了内容,Agent 那边没生效?

本地来源的修改是实时生效的(软链直连)。如果是 GitHub 来源,更新需要你在「待办」页确认应用——这是刻意的安全设计,见 [更新与待办](/guide/updates)。
