# 下载安装

## 安装 SkillDock

### macOS

1. 从 [Releases](https://github.com/qlql489/skill-dock/releases) 下载最新的 `.dmg`
2. 双击打开,把 SkillDock 拖进「应用程序」
3. 启动应用

同时支持 Apple Silicon (arm64) 和 Intel (x86_64)。

### Windows

从 [Releases](https://github.com/qlql489/skill-dock/releases) 下载 `.msi` 安装包,双击运行,按向导完成安装。

## macOS 提示「无法验证开发者」怎么办

首次打开如果弹出「无法验证 App 是否包含恶意软件」或「无法打开,因为无法验证开发者」:

1. 先把弹窗关掉(点「完成」)
2. 打开「系统设置」→「隐私与安全性」
3. 滚动到「安全性」区域,点击「仍要打开」
4. 输入登录密码确认,再次打开 SkillDock

「仍要打开」按钮通常只在第一次被拦截后的约 1 小时内出现,出现后尽快点。

## 需要额外装什么吗

- 日常使用:**不需要任何额外依赖**
- 添加 GitHub 来源或使用技能市场:需要系统 `git` 和 `curl`(macOS 自带;Windows 建议安装 [Git for Windows](https://gitforwindows.org),它同时提供 `git` 和 `curl`)
