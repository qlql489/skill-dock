# 本机 skill 管理

用 SkillDock 之前,你大概率已经在各个 Agent 目录里手动装了一堆技能。这一页就是把它们纳入管理的地方。

## 两种视角

「本机skill管理」页有两个 tab:

- **全局视角**:所有已启用 Agent 的总览
- **Agents 视角**:左边选一个 Agent(含未启用的),右边列出该 Agent 技能目录里的全部内容,按组呈现

## 收编(Accept)

对任意已存在的技能点收编:

- 技能目录移入中央技能库(或登记其来源)
- 原位置换成指向中央库的软链
- Agent 侧完全无感——路径没变,内容没变

收编后,这个技能就进入统一的技能库:可搜索、可打组合、可分发到其他 Agent。

## 不收编行不行

行。未收编的技能照常显示在列表里,应用不会动它。收编是可选动作,只是不收编就不能享受跨 Agent 分发和统一更新检查。

## 常见问题

### 收编会丢文件吗?

不会,是「移动 + 建链」而不是复制。Agent 目录里的软链指向中央库的新位置,打开效果和原来一样。

### 收编后想改回去?

从技能详情页卸载所有 Agent,再手动把目录从中央库移回原位即可。应用不锁定任何文件。
