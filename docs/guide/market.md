# 技能市场

市场页内置三个技能市场的搜索与热门榜单,不用离开应用就能发现新技能。

## 支持的市场

| 市场 | 形态 | 接入方式 |
|------|------|----------|
| [skills.sh](https://skills.sh) | 技能榜单 | GitHub 克隆安装 |
| [SkillHub](https://skillhub.tencent.com)(腾讯) | 搜索 + 榜单 | API + zip 下载 |
| [ClawHub](https://clawhub.ai) | 搜索 + 榜单 | zip 下载 |

## 使用方式

1. 进「市场」页,搜索关键词或浏览热门榜单
2. 点开技能看简介
3. 一键安装——技能进入中央技能库,此后和本地技能完全同等地管理、组合、分发

## 同名技能怎么处理

同一个技能 ID:同源安装会覆盖原技能(正常更新);异源安装会以 `-N` 后缀并存,不会互相覆盖。

## 一条实用建议

市场技能质量参差,安装后先在详情页读一遍 `SKILL.md` 再决定铺到几个 Agent;觉得不错的本地改造成自己顺手的样子——反正改完更新检测会如实标出差异,不会被上游覆盖。
