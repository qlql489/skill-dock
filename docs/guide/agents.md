# Agents 与安装

「agents」页是所有已接入 Agent 的浏览和管理入口。

## 内置目标

应用内置 38+ 主流 Agent 的技能目录定义:Claude Code、Codex、MiniMax Agents 默认启用;Trae、CodeBuddy、Kiro、Qwen Coder、Qoder、Lingma、iFlow、Kimi Code 等按需开启。完整列表在应用的「agents」页查看。

- **自动探测**:启动时检测本机实际安装了哪些 Agent,探测到的自动启用;页面上有「重新检测」按钮
- **自定义目标**:任何有技能目录的工具,手动填路径即可接入,和内置目标同等对待
- **排序与开关**:已启用的列表支持拖拽排序;未启用的收进折叠面板,开关即启用/停用

## 安装是怎么工作的

安装 = 在 Agent 的技能目录里建一个指向来源技能的**符号链接**:

- 改技能文件,所有 Agent 立即看到新内容(同一份文件)
- 卸载 = 删软链,来源文件原地不动
- 应用启动时会「对账」(reconcile):被手动删掉或指向失效的软链会如实标记为「失效」

## 三种安装入口

1. **技能详情页**:Agent 开关卡片网格,一次开一个
2. **卡片图标角标**:卡片视图下直接点,不进详情页
3. **组合**:一组技能按预设勾选批量应用,见 [组合](./combos)

## 添加来源时默认安装

设置 → 通用 → 「添加 skills 默认安装到已启用的 Agents」:打开后,添加来源的安装步骤会自动勾选所有已启用的 Agent,点确定完成安装;关闭则每次手动挑选。

## 常见问题

### 安装时报「真实目录冲突」

目标位置已有同名真实目录(不是 SkillDock 建的软链)。应用永不覆盖真实目录——把旧目录移走或改名后重装即可。

### 别人建的软链能接管吗?

可以,但只在显式确认后替换(「Replace」确认框)。SkillDock 自己建的链接则可以直接卸载或重装。
