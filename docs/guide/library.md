# 技能库与来源

技能库是应用的主页面,左边栏计数就是它的技能总数。

## 来源类型

点 **+ 添加skills** 可以添加三类来源:

- **本地文件夹**:目录里每个含 `SKILL.md` 的子目录算一个技能。适合放你自己写的、或用别的方式下载的技能
- **GitHub 仓库**:填 URL,后台克隆到应用数据目录的 `repos/`,失败可重试。适合跟随别人维护的技能集
- **压缩包**:`.zip` / `.skill` 文件,安全解压(拒绝路径穿越)后入库

技能市场装的技能也会进中央库,和普通来源一视同仁,见 [技能市场](./market)。

## 技能库页面

顶部是来源维度:来源 tab(全部 / GitHub / 本地)各自带独立的搜索和排序;平铺视图下还有组合行和「展开技能」层级。

两种视图随时切换:

- **单行列表**:紧凑,适合快速扫
- **多列卡片**:名称 + 描述 + chips + 来源 + 行尾启停开关,卡片上每个已启用 Agent 有一个图标角标,点角标即为该 Agent 装/卸

## 技能详情页

点技能行进详情页:

- 简介在头部,可直接查看渲染后的 `SKILL.md`,也能切编辑器改——保存写回来源文件,更新检测的哈希会跟着更新
- Agent 区是图标 + 开关的卡片网格,铺在简介下方,点开关即装/卸

## 自动检查

启动时和每 30 分钟,应用会检查所有来源:

- 本地来源:文件变更(有文件监听,平时实时同步)
- GitHub 来源:`git ls-remote` 比较远端 SHA,**绝不自动 pull**

发现更新的来源会出现在「待办」页和来源页角标,见 [更新与待办](./updates)。

## 常见问题

### 删掉 SkillDock,技能会丢吗?

不会。技能文件永远留在来源目录,`state.json` 只记索引和软链。应用删了,来源目录和 Agent 目录里已装好的软链(会变成死链)之外不受影响。
