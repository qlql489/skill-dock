# 功能指南

这一章覆盖 SkillDock 的日常使用:技能库、Agents 安装、组合、本机纳入管理、市场和更新。

## 建议阅读顺序

1. [技能库与来源](./library) — 技能的进出口,最重要的一个页面
2. [Agents 与安装](./agents) — 安装到哪、怎么装、怎么卸
3. [组合](./combos) — 一组技能一键应用
4. [本机 skill 管理](./local-skills) — 把已散落的技能收编进库
5. [技能市场](./market) — 从 skills.sh / SkillHub / ClawHub 发现技能
6. [更新与待办](./updates) — 来源更新怎么确认,异常软链怎么处理

## 核心工作流

SkillDock 的一切都围绕一条链路:

```
来源(本地/GitHub/压缩包/市场)
   ↓ 递归索引 SKILL.md
中央技能库(每技能只有一份文件)
   ↓ 符号链接
各 Agent 的技能目录(实时生效)
```

理解了「安装 = 建软链」,大部分行为都变得直白:为什么改完即生效、为什么卸载无残留、为什么更新前要看预览(软链直连,拉了就传导到所有 Agent)。

## 和纯手工管理的关系

你可以继续用任何编辑器直接改来源目录里的技能文件——SkillDock 只是索引和链接的维护者,不锁定你的文件。想反方向操作时,「本机 skill 管理」能把 Agent 目录里已有的技能纳入管理。
