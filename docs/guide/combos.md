# 组合

组合(Group)把一组技能打包成一个可复用的单元,一键应用到所选 Agents。

## 典型场景

你给前端开发准备了一组技能(code-review、git、docs),希望在不同机器、不同 Agent 上随时一键铺开——打成组合,之后每次都是一次点击,而不是在几十个技能里逐个找。

## 编辑组合

组合编辑弹窗有两个 tab:

- **成员**:勾选哪些技能属于这个组合
- **应用到 Agents**:勾选要把组合铺到哪些 Agent

保存时同步执行勾选:新勾的 Agent 补装,取消勾选的卸载——不需要再找单独的「应用」按钮。

## 组合行

技能库的平铺视图(「全部」来源 tab)下,组合显示为独立的一行:胶囊 + 共 N 个成员。点开可以看到成员明细;组合筛选只在平铺视图生效,按来源 tab 下整行隐藏。

## 和手动开关的区别

手动开关(详情页/角标)是「一次一个技能 × 一个 Agent」的精细操作;组合是「一组技能 × 一组 Agent」的批量声明。两者可以混用:先用组合铺底,再用开关微调单个技能。

## 一条实用建议

组合按「用途」命名而不是按「来源」命名:「前端开发」「写作辅助」比「某某仓库技能」更不容易过时。
