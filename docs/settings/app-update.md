# 应用更新

设置 → 应用更新 负责两件事:检查来源更新,以及升级 SkillDock 自身。

## 来源更新

「来源更新」行 + 「检查更新」按钮:立即检查所有 Git 来源是否有新提交,结果显示在按钮旁,发现更新的来源会进「待办」。这是 [来源更新检查](/guide/updates) 的手动入口。

## SkillDock 自身的升级

- **自动检查**:启动 8 秒后静默检查一次,之后每 10 分钟一次;发现新版本会弹 toast 提醒,不打断当前操作
- **手动升级**:设置 → 应用更新 → 单按钮状态机——「检查更新」→「下载并安装 vX.Y.Z」(带进度条)→「重启应用」,三步完成
- **下载安装始终需要确认**:自动检查只提醒,绝不后台静默升级

## 更新包安全

- 更新包带 minisign 签名,客户端内置公钥校验,签名不符直接拒绝安装
- 检查到的版本号、下载地址都来自 GitHub Releases 的 `latest.json`

## 常见问题

### 提示「自动更新未启用」

说明 updater 签名公钥还没填真实值，应用会优雅禁用而不是报网络错误。开发者配置方法见 [发布流程](https://github.com/qlql489/skill-dock#开发者发布新版本)。

### 检查失败:未找到 latest.json

新版 Release 已打 tag 但产物没传全(缺 latest.json)。等 Release 工作流跑完再检查;旧版本请直接去 Releases 页下载安装包。
