# 设置与原理

这一章讲设置页的每一块做什么,以及应用背后的安全边界。

## 设置页结构

设置页目前只有一个「通用」区块,包含:

- **外观**:主题色(预设 + 自定义)
- **添加来源**:「添加 skills 默认安装到已启用的 Agents」开关
- **同步**:中央仓库路径、状态文件位置、默认同步方式(符号链接)
- **应用更新**:当前版本、检查/下载/安装,以及来源更新检查入口

各页导航:

- [外观与通用](./appearance)
- [应用更新](./app-update)
- [数据目录与安全模型](./data)

## 一条使用建议

设置项都带即时生效的说明,改完不用重启;真正需要你理解的只有两件事——中央仓库在哪(同步区块),以及哪些操作会碰你的文件(安全模型)。
