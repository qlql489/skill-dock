# 外观与通用

## 主题颜色

设置 → 外观:六个预设主题色 + 自定义取色器。全部强调色(按钮、开关、选中态、进度条)都从所选颜色实时派生,切换即时生效并持久化,下次启动保持。

## 添加 skills 默认安装到已启用的 Agents

设置 → 通用:

- **开**(默认):添加来源的安装步骤自动勾选所有已启用的 Agents,点确定即完成安装
- **关**:每次添加来源都手动挑选安装目标

「已启用的 Agents」指「agents」页里开关打开的那些,和是否检测到本机安装无关。

## 中央仓库路径

设置 → 同步:显示中央仓库位置（新安装默认位于 `~/.skill-dock/`）,可以更改目录,也可以一键在访达中打开。状态文件 `state.json` 存的就是来源、Agent、安装关系和组合配置,详见 [数据目录与安全模型](./data)。

## 默认同步方式

目前是「符号链接」,文件复制模式暂未开放(界面上置灰)。软链模式下修改来源文件对所有 Agent 实时生效,这也是整个更新安全模型的前提。
